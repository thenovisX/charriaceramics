# Charria Ceramics · Diseño elegido: Editorial

Opción elegida para desarrollar la web: `opcion-1-editorial`.
Abre `opcion-1-editorial/index.html` con Live Server (clic derecho → Open with Live Server).

- Estilo editorial tipo Zara Home: marfil y negro, Bodoni Moda + Montserrat 300/400 (letter-spacing 0.05em).
- Secciones: tienda (columnas con parallax), clases en grupo (lista con imagen flotante y modal de reserva),
  clase privada 1 a 1 (imagen fija + formulario), galería (scroll horizontal fijado).
- Librerías por CDN (versiones fijas): Lenis 1.1.13, GSAP 3.12.5 + ScrollTrigger, SplitType 0.3.4.
- Imágenes de Unsplash; si alguna no carga se muestra un fondo color barro en su lugar.
- Cesta, formularios y reservas son simulados (sin backend).

Las otras dos propuestas (taller inmersivo y catálogo) siguen en el historial de git (commit 7882be6).
